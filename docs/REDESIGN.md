# OpenExam 改造规划 · 从「刷题工具」到「备考待办」

## 0. 问题诊断

现状是**工具视角**：题库 → 组卷 → 考试 → 报告。
用户是**备考者视角**：今天该干哪几件事，干完没有。

家底盘点（`data/openexam.seed.db`）：

| 项 | 现状 |
| --- | --- |
| 题库 | 161 套卷 / 18686 题，2022–2026，全国 + 31 省齐全 ✅ |
| 逻辑填空 | 2077 题 —— 词语库的矿源 ✅ |
| 申论 | 0 条 ❌ 全库只有行测客观题 |
| 笔记 | 无 ❌ |
| 每日待办 | 无 ❌ |
| 考点粒度 | 只到二级（`ziliao/zonghe` 2689 题一锅烩）⚠️ |
| 考试类目 | 考公 / 事业单位 / 考研 / 自定义 → **收敛为 公务员 + 事业单位** |

## 1. 核心主张

**首页 = 今日待办清单。** 不是「做了多少题」，是「今天这几件事干完没」。

待办**不写死**：系统预置 4 条模板，用户可增删改停用，也可加纯自定义条目。
预置只是「开箱即用的默认」，不是「产品硬性四关」。

## 2. 待办模型

### `todo_templates` —— 可编辑的每日任务模板
```
id, title, kind, config(json), target(json), repeat, sort, enabled, created_at, updated_at
```
- `kind`：`vocab` | `essay` | `drill` | `note` | `custom`
- `target`：`{unit:'count'|'minutes'|'once', value:N}`
- `repeat`：`daily` | `weekdays` | `weekly:1,3,5`
- `config`：各 kind 自己的参数（如 drill 的 `{mode:'weak', category, province}`）

### `todo_instances` —— 每天按模板生成的实例
```
id, template_id, date, title, kind, config, target, progress, status, done_at, meta
```
- `status`：`todo` | `doing` | `done` | `skipped`
- **进度自动回写**：背词 / 交申论 / 刷题时自动累加 `progress`，达标自动 `done`
- `custom` 类型手动勾选
- 昨天未完成 → 今日顶部「欠账」提示，可一键顺延

四条预置模板（首次启动写入，随便改）：
1. 词语积累 · 15 个 → `vocab`
2. 申论归纳概括 · 1 道 → `essay`
3. 行测专项 · 薄弱考点 30 题 → `drill`
4. 当日复盘笔记 · 1 条 → `note`

## 3. 四类能力

### 3.1 词语库 `vocab`
- **来源**：离线脚本扫 2077 道逻辑填空，抽成语/实词/关联词，AI 批量补「释义 / 用法 / 易混辨析 / 真题例句」灌进种子库 —— 一次性生成，日常零 token
- **每日** = 新词 + 到期复习词（SM-2 间隔重复，错了缩短间隔）
- **形式**：辨析卡 → 立刻抽 3 道真题填空验收
- 表：`vocab`、`vocab_reviews`

### 3.2 申论批改 `essay`
- 题型：归纳概括 / 提出对策 / 综合分析 / 贯彻执行 / 大作文
- 流程：材料 + 题干 + 字数限制 + 计时 → 作答 → AI 五维批改
  - 要点覆盖率 · 踩分点逐条 · 概括层次 · 语言规范 · 字数
  - 明确输出**漏了哪几个点、为什么漏**
- 一键把漏点沉淀成笔记
- **题源三条路**：手动录入 / AI 生成 / 文件导入（PDF、图片 OCR 复用现有 ImportPaper 管线）
- 表：`essay_prompts`、`essay_attempts`

### 3.3 行测考点 `drill`
- 建**三级考点树**：模块 → 题型 → 考点（资料分析 → 增长 → 基期量／年均增长率）
- 每考点带**掌握度**（正确率 × 时间衰减）
- 今日推荐 = 2~3 个薄弱/到期考点 × 每个 8~10 题
- 省份维度独立：锁定目标省真题，或全国混刷
- 表：`skill_points`、`skill_mastery`

### 3.4 笔记与知识库 `note`
- **常驻右侧抽屉**，任何页面随手记，自动带上下文（这道题 / 这个词 / 这道申论）
- Markdown + 标签 + **FTS5 全文搜索**
- 笔记 + 词库 + 申论漏点 → 统一 `kb_chunks`，**AI 导师回答前先检索本地库**
- 表：`notes`、`notes_fts`、`kb_chunks`

## 4. 导航重构

```
今日 | 词语 | 申论 | 行测 | 笔记 | AI 导师 | 我的
```
成长 / 成就 / 分析 / 设置 收进「我的」。首页只剩今日待办 + 一条极简进度条。
